# Какая библиотека за что отвечает (скелет слайдов)

Короткий конспект для лекции: одна мысль — один слайд.

## Слайд 1. Что такое KASP
- Два аллель-специфичных праймера (AS1/AS2) + один общий (COM).
- Дискриминация держится на **одном** основании 3'-конца AS.
- Следствие: всё решает дизайн праймеров и его контроль.

## Слайд 2. Принцип: ничего не считаем руками
| Шаг | Библиотека | Почему ей |
|-----|-----------|-----------|
| Tm | `TmCalculator` | NN-термодинамика (SantaLucia 2004), соль/DMSO |
| Аллельная дискриминация | `DECIPHER` (`CalculateEfficiencyPCR`) | гибридизация + эффективность достройки Taq |
| Шпильки/димеры | OligoArrayAux (`hybrid-ss-min`/`hybrid-min`) | реальные dG ДНК |
| Специфичность | `Biostrings` (`PDict`, `matchProbePair`), `rBLAST` | точный/быстрый поиск |
| Ввод | `vroom`, `Rsamtools` | потоково и по индексу |
| Графика | `ggmsa`, `gggenes`, `ggrepel`, `patchwork` | предметные панели, не ручные геомы |

## Слайд 3. Геометрия — в одном месте
- `primer_interval()` / `as_anchor()` — единый источник координат.
- Дизайн, сборка теста и графики используют одни интервалы → рисунок не расходится с дизайном.

## Слайд 4. Дизайн и вовлечённость физики
- Перебор кандидатов (цепь × длина × мисматч).
- Победителя выбирает `DECIPHER` по дискриминации, а не «правило на глаз».
- InDel: сканируем стык, каждое размещение оценивает та же физика.

## Слайд 5. Что такое «хороший KASP»
- `kasp_design_checks()` → tidy `criterion / observed / limit / pass`.
- Пороги: LGC/KBioscience + EasyKASP 2025.
- Один вызов — вердикт по всем пунктам.

## Слайд 6. Воспроизводимость
- `renv` пиннит версии; `R CMD check` — Status OK; тесты наследуют namespace.
- Живой прогон: `vignette("kasp-intro")`, `inst/scripts/quickstart.R`.
