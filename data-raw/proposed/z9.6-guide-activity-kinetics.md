> `Z9.6` CRISPR: несколько спейсеров, активность, кинетика репортёра.**

>   `R/marker_readout.R` — кинетика как `simulated = FALSE` до набора данных.
>   Проверка: `test-crispr.R`; `test-readout-physics.R`.
>   Блокер: `Q2` (`crispr_seed_rule`) для величины; набор «guide → активность» для
>   кинетики.
>   Следствие: один спейсер, выбранный по `off_target`, выходит как «лучший» без
>   альтернатив.

Three distinct questions hide in that blocker:

1. **Spacer multiplicity** — can `crispr_guide_candidates()` return a *ranking*?
   Today it returns candidates sorted by `v_off` + `gc_dev` (`R/marker_crispr.R:243-248`)
   and `crispr_design_marker()` takes the first. Is there a published axis to rank on?
2. **guide → activity** — is there a real dataset of (spacer sequence) → (measured activity)
   that could replace the shape filter with a number?
3. **Reporter kinetics** — does a real per-guide kinetics table exist, so that
   `readout_profile()` can say `simulated = FALSE` honestly?

## 3. Findings

### 3.1 What axis actually predicts guide activity?

|---|---|---|---|---|---|
| Specht 2020, PNAS | 10.1073/pnas.1918685117 / PMC7260945 | matched-guide activity spread at **fixed 50 % GC** | "the relative reconfiguration rate ν for all fully matched crRNA–DNA targets falls within a very narrow range of **1.00 ± 0.06**" | Results, Fig 5C | **No** for GC at fixed composition — GC cannot rank |
| same | same | PAM is an activity axis | "DNA binding … proximal to a TTTV PAM site is **2.8 times** more efficient than a TTV PAM site" | Results, Fig 3B/C | **Yes**, and the package already gates on `^TTT[ACG]$` |

| Dalla Costa 2024, Plant Direct | 10.1002/pld3.627 / PMC11328349 | LbCas12a in planta, guide vs off-target | "mismatches in the first 20 nt … decreased … the in planta editing rates by **10–>100 fold**"; "bases **21–23** … highly tolerant" | Results, Fig 5b | position yes; per-guide level no |
| same | same | what the "best" guide actually delivers | "edited plants free of off-target editing could be found in **39/60 (65 %)** of the original T0 Promiscuous plants compared with **59/59** of the original T0 Unique plants" | Results, Fig 5c | **the uniqueness gate does the work**, not the activity score |

**Interpretation.** A *ranking* by predicted activity has weak support
(r ≤ 0.6, Aulak Table 1) and **GC is explicitly not that axis** (Specht
Fig 5C: 1.00 ± 0.06 across matched guides at 50 % GC). The one axis with a
measured multiplier the package can use without new data is **PAM quality**
(2.8× TTTV over TTV, Specht Fig 3B/C) — but `crispr_guide_candidates()` already
enforces `^TTT[ACG]$`. So the honest change for `crispr_guide_candidates()` is
to **report all candidates with the evidence it has**, not to invent a ranking.

## 5. Verdict

**Can be wired without a new model (now).**

- `crispr_guide_candidates()` **multiplicity**: return *all* candidates with the
  columns already present (`v_off`, `gc`, `pam`, `pfs`, and `off_target` hits
  from `crispr_spacer_hits()`), and expose an **explicit `rank_basis`** column
  whose value is `off_target` (the only axis with measured consequences:
  Dalla Costa Fig 5c, 59/59 vs 39/60). That is exactly the roadmap's
  "ранжирование нескольких спейсеров" — a list plus a documented basis — and
  the literature supports it.
- `R/marker_readout.R` **kinetics**: keep `simulated = FALSE`, but now with a
  **named reason and a citation**: Liang Fig 3C/D shows the PM/MM contrast is
  time-dependent (early phase vs 2 h) and CSDA-specific, so a generic Cas12a
  time-to-signal curve would be wrong. That converts an honest flag into a
  documented one.
- **GC must not become the tie-breaker.** Specht Fig 5C (1.00 ± 0.06) is direct
  evidence against it; the current `gc_dev` sort in `R/marker_crispr.R:246-248`
  is therefore a shape constraint, not an activity predictor, and should not be
  presented as one.

**Needs a model (not wireable as-is).**

- A `guide → activity` predictor from spacer sequence: the only published
  corpus is HT 1–1 (**15,000** guides, Aulak Discussion), and every model on it
  reaches r ≤ 0.6 with an endogenous set of **55** guides diverging. Wiring it
  means importing a 15 k-row dataset and a trained model (DeepCpf1) with a
  documented r ≈ 0.4–0.58 ceiling. That is a new dependency, not a lookup.
- A reporter-kinetics curve: Liang gives ratios at 2 h and a "<60 min" early
  phase, but the full fluorescence trajectory values are **inside Fig 2/3
  only** (the XML carries figure captions, not the curve data). Extracting them
  is figure digitisation, which is the same status as the Jones Model-V
  coefficients in `z5.2-crispr-seed-magnitude.md`.

**Genuinely not in the literature (queries named).**

- A **per-guide, per-timepoint** Cas13a/Cas12a collateral fluorescence table
  keyed to spacer sequence at the package's scale: `Cas13 AND collateral AND
  kinetics AND "time-to-signal"` → 8 hits, all fixed-endpoint diagnostics;
  `Cas12a AND collateral AND kinetics AND "time to signal"` → 16 hits, all
  diagnostics reporting one LOD/time. **Not found.**
- Any demonstration that a scoring-based guide *ranking* improves a
  diagnostic-readout outcome: Dalla Costa measures editing in plants, not
  collateral signal. **Not found.**

**Net (honest).** Z9.6's **multiplicity** half is closable now, and the right
change is a *list with a stated basis* (`off_target`), not a predicted-activity
ranking — the literature says sequence→activity is r ≤ 0.6 and GC is a non-axis.
The **kinetics** half is honestly `simulated = FALSE` and stays so; the new
evidence (Liang) makes that *documented* and shows a generic curve would be
wrong because the effect is time- and mode-dependent. There is no real
`guide → activity → time-to-signal` dataset to wire.
