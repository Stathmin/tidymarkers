# Z0.2 — dPCR Tm-window calibration: what the literature can and cannot anchor

Literature pass, 2026-11-03. Builds on `data-raw/proposed/z0.2-dpcr-tm.md`
(residual recomputation, 30-paper sweep) — re-run nothing, that file stands.
Candidate table: `z0.2-dpcr-tm-anchor.candidates.csv`.

## 1. Answer up front

**No measured dPCR/qPCR oligo Tm with its own numeric salt/Mg exists in the
searched literature.** The 44–50 °C window still cannot be anchored to a
measured set, so `Z0.2` stays blocked by `ZW3.4`.

What *is* new: the window can be anchored as a **filter on `primer_tm()` rather
than a claim about annealing temperature**, because four independent labs print
where working dPCR assays actually anneal.

## 2. New evidence — the annealing-temperature band, not oligo Tm

| candidate | doi / pmcid | number | measured how | what it calibrates |
| --------- | ----------- | ------ | ------------ | ------------------ |
| 8-plex RT-ddPCR (Foods 2024) | 10.3390/foods14010002 / PMC11720528 | 53.1 °C optimum from 51.0–62.0 °C | gradient, highest positive droplets | lower edge of the working band |
| Multiplex ddPCR, tick-borne (Pathogens 2026) | 10.3390/pathogens15020212 / PMC12943299 | 55 °C optimum from 50–63 °C | gradient | middle |
| Brucella ddPCR (PLoS NTD 2023) | 10.1371/journal.pntd.0011367 / PMC10237378 | 55.3 °C optimum, 12 steps 50.0–62.0 °C | gradient | middle, steps printed |
| IDH1/2 ddPCR (IJMS 2025) | 10.3390/ijms262110397 / PMC12610676 | 56.5 °C fixed, gradient 55.0–60.0 °C | gradient, 4-cluster separation | upper edge |

Band: **53.1–56.5 °C**. Every one of the four probes/primers works with a
`primer_tm()` reading **~9 °C lower** (mean 48.06 °C on mm2020): 53.1 − 9.3 ≈ 44,
56.5 − 9.3 ≈ 47. The package's 44–50 °C window is, numerically, *this band
shifted by the model's own bias* — which is why it selects working assays, and
why moving it while the bias is unexplained would over-select.

## 3. New evidence — the readout floor

| candidate | doi / pmcid | number | what it calibrates |
| --------- | ----------- | ------ | ------------------ |
| Digital MCA (Biosensors 2025) | 10.3390/bios15010036 / PMC11764372 | 0.5 °C instrument precision; ddPCR melt sits 1.1 °C below HRM (6 amplicons) | a dPCR Tm-separation rule below 0.5 °C is unobservable; an HRM-derived threshold is 1.1 °C too high |
| dHRM KRAS (JCM 2020) | 10.1128/jcm.00325-20 / PMC7269394 | WT 68.7 / G12R 66.3 / G12D 62.6 °C, sd 0.2 °C | one SNV in a molecular beacon moves Tm >3 °C |

The 1.1 °C platform offset is the only *measured* cross-platform Tm difference
found, and it is two orders of magnitude smaller than the −16.86 °C bias.

## 4. The Mg term, bounded for the first time

Zhou 2025 (`F96SK3PY`, 10.1371/journal.pone.0321885 / PMC12002481, HRM of
diatom amplicons) states the averaged model error reaches **1.77 °C** once
[Mg2+] exceeds 2 mM, and that the method requires Mg **1.5–2 mM**. This is the
first *printed* number for how big a Mg term in a Tm residual can be. It is
small in both sign and magnitude compared with −16.86 °C, so **Mg is ruled out
as the explanation of the bias, not merely unmeasured**. Mg is 0 in mm2020
anyway; this makes the "just correct for Mg" path formally closed.

## 5. What this licenses

Nothing about the window value. It licenses two note-only edits, both already
implied by `Z0.2`'s text:

1. The 44–50 °C window is **not** an annealing temperature; it is a lower bound
   on `primer_tm()`. Working dPCR assays anneal at 53.1–56.5 °C (§2).
2. A dPCR Tm-separation criterion should not be set below **0.5 °C** (§3).

Both are documentation, not behaviour. Window unchanged; `ZW3.4` stays open.
