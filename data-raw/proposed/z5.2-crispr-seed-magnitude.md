Two separate claims in that quote are attacked here:

1. **CRISPR**: "not a fold-signal from which a weight can be fitted" and
   "no per-target predictability". Question: does the literature publish a
   **per-position, per-base** mismatch magnitude that is transferable enough to
   become a weight?
2. **RPA**: "no published magnitude, only a binary success probability 0.59–0.984".
   Question: is that true? (Answer: **no** — see §3.2.)

Out of scope here: KASP 3′-anchor (Lefever 2019 + Kwok 1990 already encoded,
`z5.2-family-magnitudes.md` §KASP), LAMP, HRM, CAPS.

**What this changes.** The previous verdict ("gate, not gradient") was correct
about *what the diagnostic Cas13 papers print*, but it was checked only on Cas13
and one Cas12a diagnostic paper. On the **Cas9/Cas12a biochemical** literature
the behaviour is not only a count gate: there is a **structured position axis**
with published magnitudes in three independent assay geometries:

- SpCas9: seed 1–9 is a *>100-fold* cliff, 10–17 is a 10–100× ramp, 18–20 is flat
  (Jones, NucleaSeq).
- SpCas9: the same cliff expressed as a **~5 k_B T per-mismatch penalty** with
  per-position variation (Eslami-Mossallam, kinetic model).
- Cas12a: a *>100-fold* vs *<10-fold* two-band split at position 8/9
  (Jones), plus an **additive** single-mismatch energy (Specht).

**What remains true.** None of these predicts an arbitrary target's fold-signal
from its sequence: Specht's own position dependence is non-monotonic (Fig 4F),
Eslami-Mossallam's 33 equivalent solutions show the weights are underdetermined,
and every per-guide sequence→activity model on Cas12a sits at r ≤ 0.6 (Aulak
Table 1). So `crispr_seed_rule` is **still `unknown`** as a *fold-signal* — but
it is **no longer `unknown` as a position weight**.

**A tension to record, not smooth.** The in-repo `communbiol2024_crrna_ratio.csv`
and `R/` notes say the seed "does not order by distance from the PAM"; Jones,
Eslami-Mossallam and Aulak all say it **does** (PAM-proximal 1–9 is the
high-sensitivity window for Cas9; 1–8 for Cas12a). The in-repo set is Cas12a
**cleavage-ratio** data counted from the 5′ end of the crRNA, which is the
opposite numbering convention from NucleaSeq's "position 1 = PAM-proximal".
Both can be right about their own axis; the numbering must be stated per row.

### 3.2 RPA — the roadmap's "no magnitude, only a probability" is **wrong**

Higgins 2022 (J Mol Diagn, 315 major/minor/gross primer–template mismatch
combinations across 7 assays) reports three continuous metrics against a
fully-matched control: **TP** (time to positivity, % increase), **MG** (maximum
gradient, % decrease) and **TMG** (time to maximum gradient, % increase).

| source | DOI/PMCID | what is reported | exact number / units | page/table/figure | per-target predictable? |
|---|---|---|---|---|---|
| Higgins 2022 | 10.1016/j.jmoldx.2022.08.005 / PMC12179515 | TP by mismatch position | lone **terminal**: **+17.7 %** TP; **1n/3n**: not significant on TP | Results "The Impact of Primer-Template Mismatch Location", Fig 4B | **partly** — position-only model R² 0.791 |
| same | same | MG by mismatch position | terminal **−19.4 %**; **1n −9.7 %**; **3n −15.3 %** | Fig 4D | **partly** — R² 0.826 |
| same | same | TMG by mismatch position | terminal **+51.7 %**; 1n **+13.2 %**; 3n **+11.1 %** | Fig 4C | R² 0.656 — weakest |
| same | same | **two** mismatches (the Z5.2 question) | T1n **+34.17 %** TP / **−40.13 %** MG; T3n **+27.35 %** TP / **−32.10 %** MG | Fig 4B, 4D | yes, 2-MM > 1-MM at every position |
| same | same | base identity | C–C terminal: success **0.59**, TP **+37.3 %**, MG **−58.4 %**, TMG **+73.2 %**; G–A TP **+27.4 %**; T–G success **0.98** (ns) | Results "Mismatch Constituents", Fig 2 | base identity is a first-order axis |
| same | same | model quality | positional model: success AUC **0.72**, TP R² **0.792 (0.791)**, MG **0.826 (0.826)**, TMG **0.656 (0.655)**; Gibbs-dG model: AUC **0.734**, TP **0.658**, MG **0.857**, TMG **0.550** | Results (Suppl Tables S2/S3) | **position beats a thermodynamic ΔG feature** on every metric |

Two consequences that matter for the policy:

1. RPA **does** have a ratio-like magnitude: TP, MG and TMG are all *relative
   to a matched control*. The package's `max_mismatch`-only RPA branch is
   under-informed, not correct.
2. A **nearest-neighbour ΔG feature does not reproduce it** (Gibbs model R²
   0.658 vs positional 0.792 on TP, and worse on MG/TMG). So the fix is not
   "run the package's Tm machinery on the primer 3′ end" — the published best
   predictor is a **categorical position lookup**, which is exactly what
   `specificity_policy()`'s 3′ window already encodes, now with numbers attached.

## 5. Verdict

**Can be wired without a new model (now).**

- *RPA*: replace "probability only" with the three published positional bands
  (TP/MG/TMG) already in `rpa_mismatch_terminal.csv`'s source. The 2-MM numbers
  (T1n/T3n) answer the Z5.2 "несколько мисматчей" wording directly. A
  position→band lookup is a table, not a model, and it is the predictor the
  paper itself found best. Scope decision for `R/` (out of this agent's write
  scope): whether RPA gets its own `specificity_policy()` branch driven by
  terminal/1n/3n × count.
- *CRISPR*: the `seed_len` / `seed_max` window can be re-justified from Jones
  (Cas9 1–9, Cas12a 1–8) instead of the current loose constant, and the
  "two seed mismatches abolish cleavage" gate is now triangulated by three
  independent sources (Jones Fig 2c, Aulak, Specht Fig 5D). That is a
  *justification* change, not a magnitude.

**Needs a model (not wireable as-is).**

- A **per-position weight** for Cas9/Cas12a: the published coefficients are
  Eslami-Mossallam's δε₁…δε₂₀ (~5 k_B T each, Fig 4b — **values printed in the
  figure only, not in the XML text**) and Jones' two/three-band log-rate
  mapping. Fitting the figure is a research task, and the 33-solution
  underdetermination means one dataset does not pin it. This is the only
  candidate that would turn `crispr_seed_rule` from `unknown` into a number, and
  it is a *relative weight*, not a per-target fold-signal.
- Any **cross-family** weight (one scale for RPA + CRISPR + KASP) — no source
  puts these on a common axis.

**Genuinely not in the literature (named queries run).**

- RPA **3-mismatch** kinetics: Higgins tests 0/1/2 mismatches in the anchor
  region only. `"recombinase polymerase amplification" AND "multiple mismatch"`
  → 0 hits. **Not found.**
- A per-target Cas12a fold-signal for diagnostic (collateral) readout from
  sequence alone: Aulak Table 1 gives r ≤ 0.6 on editing efficiency, and the
  diagnostic papers report inversion bands whose position in the band the
  authors call unpredictable. **Not found.**
- Any confirmation that Jones' SpCas9/Cas12a in-vitro kinetics transfer to
  LbCas12a/LwaCas13a *in a RPA one-pot diagnostic*: the diagnostic papers
  (NAR 2026 PMC12961430, Adv Sci 2026 PMC13669218) do not test Cas9 at all.
  **Not found** — this transfer is an assumption, not a citation.

**Net:** the blocker moves from "no magnitude anywhere" to "a positional
magnitude exists for RPA (wireable) and for Cas9/Cas12a *biochemistry* (needs
a model + figure extraction), with the per-target fold-signal still absent".
`crispr_seed_rule` stays `unknown` for the fold-signal; its *position* part is
now evidence-backed rather than `unknown`.
