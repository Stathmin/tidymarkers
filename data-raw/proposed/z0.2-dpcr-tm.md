# Z0.2 — the dPCR Tm window is calibration debt, not a norm

**Status: window does NOT move.** `design_dpcr_marker()` keeps `tm_range = c(44, 50)`.
Blocker ZW3.4 remains open: the residual is unexplained and no measured dPCR/qPCR
oligo-Tm set with its own buffer was found to close it.

`R/marker_dpcr.R`, `tests/testthat/test-dpcr.R` are the only code touched.
`data-raw/dpcr_tm_jrc2025.R` → `inst/extdata/dpcr_tm_jrc2025.csv` lands one
_computed_ contrast set (see §3), which cannot calibrate anything.

## 1. Residual, recomputed (not copied)

`inst/extdata/tm_mm2020_s1_measured.csv`, 64 canonical 19-mers,
`reaction_conditions(Na = 50, Mg = 0, dNTPs = 0, DMSO = 0)`:

| quantity                                                     | value           |
| ------------------------------------------------------------ | --------------- |
| `bias = mean(primer_tm - measured)` (Schildkraut default)    | **-16.8643 C**  |
| sd of that residual                                          | 0.6414 C        |
| Pearson r / Spearman rho                                     | 0.9579 / 0.9413 |
| mean measured Tm                                             | 64.9250 C       |
| mean `primer_tm()`                                           | 48.061 C        |
| H1 salt term `16.6*log10(0.05)`                              | -21.5971 C      |
| **`bias - salt`** (the H2 "1 M reference is high by" number) | **+4.7328 C**   |
| `bias` with `salt_method = "Owczarzy2008"`                   | **-9.3348 C**   |
| Owczarzy closes                                              | -7.5295 C       |
| **Owczarzy residual vs salt term** (`bias_ow - salt`)        | **+12.2623 C**  |

Reproduce:

```sh
export PATH=/opt/R-4.6.1/bin:$PATH
export UNAFOLDDAT=/root/development/tidymarkers/.tools/share/oligoarrayaux
export R_LIBS_SITE=/opt/R-4.6.1/lib/R/library
Rscript -e 'pkgload::load_all(".", quiet=TRUE)
d <- utils::read.csv("inst/extdata/tm_mm2020_s1_measured.csv")
can <- d[d$mismatch_class == "canonical", ]
cond <- reaction_conditions(Na=50, Mg=0, dNTPs=0, DMSO=0)
sk <- primer_tm(can$top_18, conditions=cond)
ow <- primer_tm(can$top_18, conditions=cond, salt_method="Owczarzy2008")
b <- mean(sk - can$measured_tm_c); s <- 16.6*log10(0.05)
cat(sprintf("%.4f %.4f %.4f %.4f %.4f\n", b, s, b-s, mean(ow-can$measured_tm_c), mean(ow-can$measured_tm_c)-s))'
```

So **-16.86 C is confirmed**, and **-9.34 C is the Owczarzy remainder**. Both
match `data-raw/mm2020.R`'s hypothesis block and `test-tm-mm2020.R`'s bands.
Nothing here is new; the numbers are re-derived so the debt is cited, not assumed.

Two readings of "remains unexplained", both still open:

- default (Schildkraut): the salt term overshoots by +4.73 C, and the residual is
  a level, not a slope — Mg is 0 in this set, so Mg cannot explain it.
- Owczarzy: -9.34 C is left over and its `-salt` remainder is +12.26 C.

Either way, the model under-reads a measured set by ~9–17 C, and the ±0.64 C sd
says it is a **level** offset, not scatter.

`inst/extdata/tm_hm2025_amplicon_psaa2.csv` (5 HRM amplicons) is also unusable:
Mg/Na/K/dNTP/DMSO are blank ("not stated numerically"), so its Tm has no
stated basis. `dpcr-readout.sources.csv` (dong2015, mps2024, cheng2021,

**Interpretation.** Measured oligo Tm with a disclosed buffer is a
biophysical-chemistry practice; applied dPCR papers use a design tool and a
vendor master mix and print neither. That is why ZW3.4's -9.34 C cannot be
closed from the applied literature: the missing information is structural
(master mixes are proprietary), not a gap in searching.

## 3. What the one new set shows (`inst/extdata/dpcr_tm_jrc2025.csv`, 8 rows: six oligos, two amplicons)

`evidence_tier = "computed, not measured"`, `salt_mM`/`mg_mM` = `NA`,
`tm_method = "Primer3Plus (design tool output, …; not a UV melt)"`.

| assay  | oligo          | len | GC % | Tm C |
| ------ | -------------- | --- | ---- | ---- |
| JRC-HA | HA01-Fwd       | 22  | 50.0 | 59.2 |
| JRC-HA | HA01-Rev       | 22  | 50.0 | 60.2 |
| JRC-HA | HA01-Prb (FAM) | 25  | 56.0 | 60.9 |
| JRC-MP | MP01-Fwd       | 22  | 50.0 | 61.0 |
| JRC-MP | MP01-Rev       | 22  | 50.0 | 61.9 |
| JRC-MP | MP01-Prb (VIC) | 25  | 48.0 | 57.8 |

Assay conditions as printed: QX600 ddPCR, Bio-Rad one-step ddRT-PCR Advanced Kit
for Probes, 900 nM primers / 400 nM probes, annealing optimised by gradient
50-62 C, **60 C used**. QIAcuity runs used a Qiagen 4x One-Step Advanced Probe
Master Mix.

`data-raw/dpcr_tm_jrc2025.R` asserts the paper's own arithmetic — 8 rows, length,
GC %, amplicon size (139 / 114 bp), the primers being the amplicon's two ends,
both probes inside their amplicon — recomputed from the printed sequences. It
does **not** assert any Tm.

**What it proves, and what it does not.**

- Proves: a working dPCR assay violates the textbook rule. Neither probe is
  within +8-10 C of its primers, and the two land on opposite sides (HA probe
  +0.7 C above its hotter primer, MP probe -4.1 C below). The
  `probe_tm_margin = 8` rule in `design_dpcr_marker()` is therefore a _design
  heuristic_, not a property of assays that work.
- Proves nothing about the residual: Tm is computed, so it carries its own
  model's bias, and the buffer's [Na+]/[Mg2+] are unknown.

## 4. Can the window move? No.

1. **No measured anchor.** Every candidate is computed Tm; calibrating a model
   against another model's output reproduces the second model's bias.
2. **No buffer.** Without numeric [Na+]/[Mg2+], the comparison cannot be put on
   the `reaction_conditions()` scale at all.
3. **Even a correct anchor would not license 58-62 C.** ZW3.4's sd is 0.64 C:
   the error is a level shift. Raising `tm_range` to 58-62 C while `primer_tm()`
   is -9.34 C low would select oligos whose _true_ Tm is ~2-6 C higher than the
   filter thinks — the window would stop being a filter and become a
   mis-selection.
4. **The default is self-consistent.** 44-50 C is the textbook window shifted by
   the model's own bias. It is wrong in principle and consistent in practice;
   moving it without a fix trades a known offset for an unknown one.

Hence ROADMAP Z0.2 stays open as **debt**, and the source now says so next to
the default and in the roxygen.

## 5. What would close it

Any one of these, in order of cost:

1. **One measured oligo-Tm set with a numeric buffer**, ≥ 8 primers spanning
   50-65 C at printed [Na+]/[Mg2+], on the _length range the designer uses_
   (18-25 nt). Even a modest UV-melt table from a methods paper would do; the
   bar is "measured + buffer printed", not "dPCR".
2. **The mm2020 authors' stated basis** for the -9.34 C (what 1 M reference and
   what measurement standard they used). This is a correspondence, not a search.
3. **A measured dPCR set at a disclosed master mix** — needs a vendor to publish
   the mix's salt/Mg, or an assay run in a home-made buffer.
4. **A probe-vs-primer Tm set measured on one instrument**, to test the
   `probe_tm_margin = 8` floor that §3 shows is too strict.

Until (1) or (2), the honest state is: bias recorded, not corrected, window
pinned, debt named.

## 6. The anchor question (2026-10-29), cross-referenced from `ZW3.4`

This debt sits on the ROADMAP item `ZW3.4`; the full anchor argument is
`data-raw/proposed/zw3.4-anchor.md`. Short form, so this file stands alone:

**What a dPCR calibration would need — all four, on one instrument:**

1. **Measured**, not computed, oligo Tm (a first-derivative melt maximum).
   §3 already shows why a computed table cannot calibrate: it reproduces the
   design tool's bias.
2. **The master mix's numeric `[Na+]` / `[Mg2+]`** (plus dNTP/DMSO), so the
   measurement can be put under the same `reaction_conditions()` the model
   reads. A vendor "2x One-Step Advanced Probe Master Mix" is proprietary and
   prints neither.
3. **Probe-vs-primer Tm on the same run**, because the debt is not only the
   level: §3 shows `probe_tm_margin = 8` is a design heuristic (a working
   assay put one probe 0.7 °C _above_ and the other 4.1 °C _below_ its hotter
   primer), so the
   margin needs measuring, not only the scale.
4. **Duplexes on 18–25 nt**, the range `design_dpcr_marker()` and
   `design_as_primers()` actually design in.

**Does an external anchor exist? No.** The only measured, buffer-stated set in
the operator's library is mm2020 (`PMC8163305`, ESI Table S1: 4096 measured
19-mers at 50 mM NaCl + 10 mM Na-phosphate pH 7.4, Mg 0). It fails condition 4
of the anchor test: 19-mers only (`zw3.4-anchor.md` §1–§3). Every other
candidate in the library (hm2025, dnamate, vonahsen2001, kutyavin2000,
huguet2017, jrc2025_h5nx) fails at least one of the four conditions; the table
in `zw3.4-anchor.md` §2 lists which one for each. So `Z0.2` stays open as debt
for a _structural_ reason (proprietary master mixes and no measured 18–25 nt
set), not for lack of searching.
