## 1. What this unblocks

ROADMAP §U says SNaPshot's blocker is *"нет приора с провенансом — без него критерии
будут `rule_of_thumb`; следствие: SNaPshot-ассей сейчас проверяется только
generic-проверками праймера."*

Today `R/marker_snapshot.R` designs against six gates, all of which are engineering
defaults rather than literature numbers:

| gate | current limit | prior used |
|---|---|---|
| `gate_snapshot_placement` | 3' end immediately 5' of the variant | none (rule stated only in papers, now sourced below) |
| `gate_snapshot_comp` | GC 30–70 %, no run ≥ 4, no SSR | `SNAPSHOT_EXT_GC` |
| `gate_snapshot_unique` | exactly one perfect extension-primer site | none |
| `gate_snapshot_structure` | hairpin/homodimer dG ≥ `KASP_LIMITS$hairpin_dg` | borrowed from KASP |
| `gate_snapshot_tm` | Tm in [50, 55] °C | `SNAPSHOT_EXT_TM` |
| `gate_snapshot_amplicon` | 100–300 bp, relax 50 | `SNAPSHOT_AMPLICON` |

and `R/marker_readout.R` declares `snapshot = "peak heights not simulated"`.

This document turns the rules that named sources **state** or **measure** into
`inst/extdata/snapshot_multiplex_design_rules.csv`, and names what stays
`rule_of_thumb`.

## 3. The rule set

`inst/extdata/snapshot_multiplex_design_rules.csv`, 19 rows, generated by
`data-raw/snapshot_multiplex_design.R` (mirrors `data-raw/kutyavin2000.R`: script-root
detection, `stopifnot()` on the papers' own arithmetic, then `write.csv`).

Columns: `rule_id, parameter, rule_text, value, range, unit, outcome_definition,
evidence_tier, source_file, doi, pmcid`.

Kinds, as used in the file header: **measured** = a number printed in a paper's own
table/panel; **stated** = a design recommendation the authors make; **derived** =
read off a printed table without the authors stating it. `evidence_tier`: `moderate` =
stated rule plus the panel that follows it in one named source; `weak` = single source,
no independent confirmation; `none` = statement held but no quantitative outcome.

### 3a. Rules with provenance — quantitative

| rule_id | value | kind | tier | source |
|---|---|---|---|---|
| `sbe_sbe_tm_gc_window` | Tm 53–60 °C, GC 40–55 % on the **core** (5' poly-CT excluded) | stated | weak | zhao2026 |
| `sbe_inter_primer_tm_delta` | inter-primer Tm spread ≤ 3 °C | stated | weak | zhao2026 |
| `sbe_amp_primer_tm` | multiplex PCR primers Tm 58–63 °C | measured | weak | namdar2023 |
| `sbe_core_length` | 17–25 nt (also 18–25, 20–68 in panel tables) | measured | moderate | namdar2023, atanasovska2012, fanis2014 |
| `sbe_spacing_min` | ≥ 3 nt between same-dye products | stated | moderate | atanasovska2012, fanis2014 |
| `sbe_spacing_used_4bp` | ≥ 4 nt in a built panel | measured | weak | coutinho2014, namdar2023 |
| `sbe_spacing_used_ct5bp` | poly-CT tails force ≥ 5 nt | stated | weak | zhao2026 |
| `sbe_peak_height_floor` | 700–4000 rfu | measured | weak | dicristofaro2010 |
| `sbe_het_balance_floor` | minor/major < 0.1 = severe imbalance | stated | weak | zhao2026 |
| `sbe_dye_yield_asymmetry` | heterozygote A vs C ≈ 1 : 3.5 | measured | weak | dicristofaro2010 |
| `sbe_primer_ratio_reported` | peak follows primer concentration; **no absolute rule** | stated | none | dicristofaro2010, namdar2023, bouvet2020 |

The generator's `stopifnot()` re-checks the arithmetic these numbers imply: the
spacing ladder is strictly ordered 3 < 4 < 5; the Tm window parses to exactly
`c(53, 60)`; the 700–4000 floor has 700 < 4000; the imbalance cut is 0.1; the dye
asymmetry reads 1 : 3.5; the Tm window's floor sits above the kit's 50 °C extension
step.

## 4. What was NOT done and why

**No registry wiring.** `R/marker_scheme_registry.R` is untouched. Adding a criterion
from these rules would change the decision-DAG shape, and ROADMAP §U's own check
(`dev/check-criteria.R`) demands an `expect_dag_invariants()` fixture per new
criterion-id. That is a schema/fixture change, not a literature step, and it would
have collided with the parallel 10-agent DAG rebuild in `dev/dag-rebuild-plan.md`
(invariants C1–C14). So this work stops at "prior exists, named, with a CSV".

Consequence, stated plainly: **SNaPshot assays still face only generic primer checks.**
The priors are now citable; they are not yet consulted by the engine.

**What a follow-up wiring change would need** (not done here): map each `rule_id` to a
`CRITERION_EVIDENCE` row, add the `expect_dag_invariants()` fixture per criterion-id,
and reconcile the two number sets that disagree with the current defaults —
`SNAPSHOT_EXT_TM = c(50, 55)` vs the stated 53–60 °C window (zhao2026), and
`SNAPSHOT_EXT_LENGTHS = 18:25` vs the measured 17–25 nt (namdar2023). Neither is a
bug; both are defaults that predate the sources.

## 5. Still `rule_of_thumb`

`data-raw/proposed/u-snapshot-absent.csv`, 8 rows — no source states these, so they
were deliberately left out of the rules table rather than invented:

| rule_id | why no source |
|---|---|
| `sbe_extension_temperature` | papers quote their own reaction temperature (50 °C kit cycle), never as a primer rule |
| `sbe_extension_time_cycles` | the kit cycle (30 × 96 °C/10 s, 50 °C/5 s, 60 °C/30 s) is protocol, not design |
| `sbe_dnaddition_dntp_purity` | the premix supplies the ddNTPs; no user-side dNTP-mix constraint is stated anywhere read |
| `sbe_primer_conc_absolute` | concentrations are reported per panel (0.01–0.4 µM in the PAH panel) but never as a rule |
| `sbe_copy_number_ceiling` | no template copy-number or input ceiling for SBE |
| `sbe_amplicon_max` | published amplicons run 60–882 bp; no source states a maximum |
| `sbe_polymerase_fidelity` | nothing beyond the kit premix |
| `sbe_hetero_height_symmetric` | measured asymmetry is dye-dependent (1 : 3.5); no symmetric-height rule exists |

Also still `rule_of_thumb` inside the engine but outside this table's scope: the
uniqueness gate (`gate_snapshot_unique`) has no literature number at all, and the
structure gate still borrows `KASP_LIMITS$hairpin_dg`.
