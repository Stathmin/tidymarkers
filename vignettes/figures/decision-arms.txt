tetra-primer ARMS-PCR - decision graph

discrimination: allele-specific inner primers, sized gel bands | readout: agarose band sizes (AA/AB/BB) | zygosity: co-dominant | loci: 1 | amplicon: bounded

== stage arms (ARMS bands) ==
gates (hard = never relaxed), all applied to the same candidates (AND):
  ! HARD  inner specificity      inner 3' base matches the allele (discrimination >= min_disc)
  - soft  band gap               REF/ALT and each vs the control >= 20 bp apart
  - soft  outer control          outer control within [200, 800] bp
relaxation ladder (least grave first):
  1. outer control          floor: widen the control window
  2. band gap               floor: allow a 10 bp band gap (PAGE)
tiers (lexicographic; a later tier only breaks the earlier one's ties):
  1. inner discrimination
  2. band separation
  3. tube Tm balance
edges:
  inner specificity        -flow  -> all gates pass?
  band gap                 -flow  -> all gates pass?
  outer control            -flow  -> all gates pass?
  1. outer control         -fail  -> 2. band gap
  all gates pass?          -fail  -> 1. outer control
  1. outer control         -relax -> survivors (floors kept)
  2. band gap              -relax -> survivors (floors kept)
  all gates pass?          -pass  -> survivors (floors kept)
  survivors (floors kept)  -rank  -> inner discrimination
  inner discrimination     -rank  -> band separation
  band separation          -rank  -> tube Tm balance
  tube Tm balance          -rank  -> provisional best
  2. band gap              -doomed-> DOOMED
  all gates pass?          -doomed-> DOOMED
  provisional best         -check -> amplicon length (bp)

== assay acceptance checks ==
  check   amplicon length (bp)               [200, 800]
  check   longest homopolymer (bp)           < 4
  check   SSR (2-4 nt, >=3 copies)           <= 0
  check   inverted repeat (arms>=4, loop<=6) <= 0
  check   worst hairpin dG37                 >= -3
  check   worst cross-dimer dG37             >= -9
  check   worst homodimer dG37               >= -9
  check   off-target exact primer hits (n)   <= 1
  (reported, not re-selecting: a failed check flags the chosen marker)

edges:
  amplicon length (bp)     -check -> longest homopolymer (bp)
  longest homopolymer (bp) -check -> SSR (2-4 nt, >=3 copies)
  SSR (2-4 nt, >=3 copies) -check -> inverted repeat (arms>=4, loop<=6)
  inverted repeat (arms>=4, loop<=6) -check -> worst hairpin dG37
  worst hairpin dG37       -check -> worst cross-dimer dG37
  worst cross-dimer dG37   -check -> worst homodimer dG37
  worst homodimer dG37     -check -> off-target exact primer hits (n)
  off-target exact primer hits (n) -check -> all checks pass?
  all checks pass?         -pass  -> usable ARMS marker
  all checks pass?         -fail  -> DOOMED

DOOMED: a hard gate blocked, every soft floor was exhausted, or an acceptance check failed.
verdict: all checks pass -> usable ARMS marker; a failing check -> doomed
