# dev/ — внутренние проверки и измерения

Скрипты разработчика: то, что в обычном пакете делает CI, здесь запускается
локально (CI в репозиторий намеренно не входит — см. `CONTRIBUTING.md`).
Ни один из них не входит в сборку пакета (`.Rbuildignore`).

## `install-deps.R` — установка окружения и пакета

```sh
Rscript dev/install-deps.R
```

`pak` читает `DESCRIPTION`, качает параллельно и берёт бинарники там, где
платформа их даёт. По умолчанию ставятся `Imports`, небольшие dev/test-инструменты
и сам пакет (`R CMD INSTALL`); тяжёлые `Suggests` (аннотации, `Rsubread`, `rprimer`,
`pkgdown`) — по флагу `--with-suggests`. Это быстрый путь; `renv::restore()`
восстанавливает весь исторический dev-лок (262 пакета, включая `pkgdown`, `shiny`,
`targets`, `ggtree`, которые пакет не загружает) и на порядок медленнее.
`renv.lock` остаётся для точного пиннинга.

## `test.R` — тесты

```sh
Rscript dev/test.R                  # lean: общие контракты (≈65 с)
Rscript dev/test.R --scheme crispr  # одна семья + общие контракты
Rscript dev/test.R --full           # все тесты + внешние сверки (последовательно)
Rscript dev/test.R <regex>          # сырой фильтр testthat (совместимость)
```

По умолчанию гоняется **минимальный гейт** — общие контракты, которые
наследует каждая схема: `criteria`, `decision`, `kasp-checks`, `plot-methods`,
`technology`. Это инварианты, на которых держатся все семейства; файлы не
удалены, полный набор остаётся за `--full`.

`--scheme <regex>` добавляет к общим контрактам файлы, чьё имя подходит под
регулярное выражение (`crispr`, `lamp|rpa`, `indel` — последний захватывает и
`test-indel.R`, и `test-indel-size.R`). Регэксп, не поймавший ни одного файла,
— ошибка, а не «зелёный» прогон. Позиционный аргумент (`dev/test.R crispr`)
оставлен как сырой фильтр testthat — без добавления общих контрактов.

`--full` включает `TIDYMARKERS_FULL_TESTS=1`: BLAST+, Rsubread, rprimer,
аннотационные базы и настоящие SOCK-воркеры. `R CMD check` выставляет тот же
флаг, поэтому релизный путь не слабеет — внешние сверки пропускаются только в
lean/scheme-режимах. Полный прогон идёт последовательно (вложенные SOCK-воркеры
под воркерами testthat роняют пул), lean/scheme — в 2 воркера.

Тесты ничего не устанавливают: один раз выполните `Rscript dev/install-deps.R`
(`--with-suggests` для полного набора) — он поставит зависимости и сам пакет.

Замеры на этой машине (R 4.6.1):

| Команда | Время | Итог |
|---|---|---|
| `dev/test.R` (lean) | 1 м 04 с | 1300 pass, 0 skip |
| `dev/test.R --scheme crispr` | 1 м 06 с | 1403 pass, 0 skip |
| `dev/test.R --full` | 9 м 45 с | 3164 pass, 0 skip |
| было: `dev/test.R` (весь набор без внешних сверок, 2 воркера) | 4 м 03 с | 3133 pass, 15 skip |

## `check.R` — приёмка перед коммитом

```sh
Rscript dev/check.R --quick     # рутинный цикл: roxygen, styler, lintr, docs/artifacts
Rscript dev/check.R             # гейт перед коммитом: + фигуры + install smoke
Rscript dev/check.R --no-render # гейт без фигур
Rscript dev/check.R --full      # релизный гейт: + R CMD check --as-cran
Rscript dev/check.R --spelling  # + орфография (англ. словарь — шумно на рус. докках)
Rscript dev/check.R --render    # + тяжёлые панели (мишени, FRI) — сеть/OligoArrayAux
```

`--quick` — для рутинного цикла: только синхронность `NAMESPACE`/`man/`,
`styler`, `lintr` и граф `docs/artifacts`. Он не запускает фигуры, install smoke
и `R CMD check`; орфография — только если явно передан `--spelling`,
комбинировать с `--full`/`--render` нельзя.
Обычный запуск (без флагов) остаётся гейтом перед коммитом: те же четыре шага
плюс фигуры и install smoke. `--full` — релизный гейт: добавляет
`R CMD check --as-cran`, внутри которого идут **все** тесты, включая
биологические и внешние сверки, — полный путь не ослаблен.

Шаги по порядку: `NAMESPACE`/`man/` синхронны с roxygen → `R/` и `tests/`
форматированы (`styler`) и без линтов (`lintr`) → `docs/artifacts` → орфография
(`spelling`, только с `--spelling`) → **фигуры** (см. ниже) → сборка и проверка
(`R CMD install`/`R CMD check`). Отсутствующий инструмент — это сообщение
«skip», а не падение; провал любого шага даёт ненулевой код возврата.

Замеры на этой машине (R 4.6.1):

| Команда | Время |
|---|---|
| `dev/check.R --quick` | 37 с |
| `dev/check.R --no-render` | 39 с |

Орфография вынесена за флаг: проза (README/ROADMAP/NEWS/виньетки) русская, и
англ. словарь помечает каждое слово; английские roxygen/комментарии и так
проверяет `lintr`.

## `render-all.R` — фигуры как код

```sh
Rscript dev/render-all.R              # всё: деревья, панель мишеней, plot-smoke, screen, FRI
Rscript dev/render-all.R --skip-heavy # только деревья решений (быстро, без генома)
```

Графы решений маршрутизирует **Graphviz** `dot` (`SystemRequirements`, опционально):
стадии — кластеры, рёбра обходят узлы; рядом с каждым PNG лежат `.dot` и текстовый
двойник `.txt`. Без `dot` шаг фигур пропускается.

Картинки не рисуются руками: каждый `render-*.R` читает движок (схему решения,
константы гейтов, реестр схем), поэтому диаграммы следуют за пайплайном. Один
вход — `render-all.R`. Шаг «фигуры» в `check.R` вызывает его **на каждой приёмке**,
так что `man/figures/*.png` (то, что в README) не расходятся с кодом: если
перегенерированная картинка отличается, шаг **падает** с просьбой закоммитить
изменение — автообновление без тихого дрейфа. По умолчанию освежаются только
деревья решений (быстро, оффлайн); `--render` добавляет тяжёлые панели (панель
мишеней, FRI) — им нужны сеть/`OligoArrayAux`, на голой машине они скипаются
сообщением, а не падением. Панель `results/plot-smoke/*.png` (git-ignored) просто
перерисовывается.

## `render-gallery.R` — рисунки для виньеток

```sh
Rscript dev/render-gallery.R
```

Прогоняет реальные дизайнеры на синтетической матрице и кладёт по одному
`plot(marker)` в `vignettes/figures/<scheme>.svg` (tracked) и `.png` (local,
в `.gitignore`); виньетки вставляют SVG через `include_graphics()`.

## `bench.R` — время и память по функциям

```sh
Rscript dev/bench.R
```

Прогоняет по представительному вызову горячих функций и печатает медианное время
и объём аллокаций. С `bench` в библиотеке берётся `mem_alloc`; на голой машине —
`system.time()` и базовый `Rprofmem()`. Нужен `OligoArrayAux` (см.
`data-raw/install-oligoarrayaux.R`) — без него термодинамические строки пропускаются.

## Инструменты (в `Suggests`)

`styler`, `lintr`, `spelling`, `bench`, `profmem`, `lobstr`, `pkgdown` (и их
зависимости) запинены в `renv.lock` — ставятся `renv::restore()`. `bench`/`profmem`/
`lobstr` не обязательны: `bench.R` откатывается на `system.time()` + `Rprofmem()`.
