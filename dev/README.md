# dev/ — внутренние проверки и измерения

Скрипты разработчика: то, что в обычном пакете делает CI, здесь запускается
локально (CI в репозиторий намеренно не входит — см. `CONTRIBUTING.md`).
Ни один из них не входит в сборку пакета (`.Rbuildignore`).

## `install-deps.R` — установка окружения и пакета

```sh
Rscript dev/install-deps.R
```

`pak` читает `DESCRIPTION`, качает параллельно и берёт бинарники там, где
платформа их даёт. По умолчанию ставятся `Imports`, небольшие dev/test-инструменты
и сам пакет (`R CMD INSTALL`); тяжёлые `Suggests` (аннотации, `Rsubread`, `rprimer`,
`pkgdown`) — по флагу `--with-suggests`. Это быстрый путь; `renv::restore()`
восстанавливает весь исторический dev-лок (262 пакета, включая `pkgdown`, `shiny`,
`targets`, `ggtree`, которые пакет не загружает) и на порядок медленнее.
`renv.lock` остаётся для точного пиннинга.

## `test.R` — тесты

```sh
Rscript dev/test.R                  # lean: общие контракты (≈1,5 мин)
Rscript dev/test.R --scheme crispr  # одна семья + общие контракты
Rscript dev/test.R --full           # все тесты + внешние сверки (последовательно)
Rscript dev/test.R <regex>          # сырой фильтр testthat (совместимость)
Rscript dev/test.R --full --profile # + профиль Rprof (~20% медленнее)
```

По умолчанию гоняется **минимальный гейт** — общие контракты, которые
наследует каждая схема: `criteria`, `decision`, `kasp-checks`, `plot-methods`,
`technology`. Это инварианты, на которых держатся все семейства; файлы не
удалены, полный набор остаётся за `--full`.

`--scheme <regex>` добавляет к общим контрактам файлы, чьё имя подходит под
регулярное выражение (`crispr`, `lamp|rpa`, `indel` — последний захватывает и
`test-indel.R`, и `test-indel-size.R`). Регэксп, не поймавший ни одного файла,
— ошибка, а не «зелёный» прогон. Позиционный аргумент (`dev/test.R crispr`)
оставлен как сырой фильтр testthat — без добавления общих контрактов. Как и в
самом testthat, фильтр применяется к имени контекста, то есть к имени файла без
`test-` и без `.R` (`^plot-methods$`, не `^test-plot-methods$`).

`--full` включает `TIDYMARKERS_FULL_TESTS=1`: BLAST+, Rsubread, rprimer,
аннотационные базы и настоящие SOCK-воркеры. `R CMD check` выставляет тот же
флаг, поэтому релизный путь не слабеет — внешние сверки пропускаются только в
lean/scheme-режимах. Полный прогон идёт последовательно (вложенные SOCK-воркеры
под воркерами testthat роняют пул), lean/scheme — в 2 воркера.

Тесты ничего не устанавливают: один раз выполните `Rscript dev/install-deps.R`
(`--with-suggests` для полного набора) — он поставит зависимости и сам пакет.

### Лог и замеры

Каждый прогон пишется в `dev/logs/` (каталог в `.gitignore`: замеры
машино-зависимы и не должны попадать в `docs/artifacts.yml`, чьи хэши гейтят
зафиксированные фигуры):

| Файл                       | Содержимое                                                                                                                          |
| -------------------------- | ----------------------------------------------------------------------------------------------------------------------------------- |
| `test-<режим>-<время>.log` | весь вывод, включая итоговую таблицу testthat; на каждый файл — строка с отметкой `[+MM:SS]` от начала прогона и настенным временем |
| `test-...-files.csv`       | по файлу: `phase`, `started_at`/`ended_at` (настенное время), длительность, pass/fail/error/warn/skip, Δ кучи `lobstr` |
| `test-...-tests.csv`       | по тесту: `started_at`, длительность                                                                                                |
| `test-...-summary.md`      | `started`/`finished`/`wall`, топ медленных файлов и тестов                                                                          |
| `test-...-profile.txt`     | `summaryRprof()` при `--profile`                                                                                                    |
| `latest-*`                 | копии последнего прогона                                                                                                            |

Отметки времени отвечают на вопрос «где прогон был на 12-й минуте», не
дожидаясь конца: не нужно повторять 17-минутный `--full`, чтобы узнать, что
он делал. Собственного времени у testthat в логе нет, поэтому его ставит
репортер; `tictoc` не нужен — он лишь печатает `proc.time()`, который здесь и
так меряется, и не умеет сам цепляться к `start_file()`/`end_test()`.

Лог и CSV переписываются после каждого файла, а сводка пишется в `on.exit`,
поэтому прерванный (Ctrl-C) или упавший прогон всё равно оставляет замеры до
места остановки. Путь к логу печатается в начале и в конце.

Репортер объявляет `capabilities$parallel_updates = TRUE`, поэтому воркеры
отдают события по мере их появления, а не пачкой на `DONE`. Следствие: и в
параллельном, и в последовательном режиме `started_at`/`ended_at` и
длительности файлов и тестов — настоящие замеры. Единственное, что параллельный
прогон не даёт, — Δ кучи `lobstr`: события нескольких файлов переплетаются в
одном процессе, поэтому колонка памяти пишется только для последовательной
фазы, а если её нет ни у одного файла — не печатается вовсе (в CSV колонка
остаётся). `--profile` по-прежнему только последовательный: `Rprof` на общем
процессе с воркерами не разделяет файлы.

Замеры на этой машине (R 4.6.1); актуальные цифры — всегда в
`dev/logs/latest-summary.md`:

| Команда                                                       | Время    | Итог                            |
| ------------------------------------------------------------- | -------- | ------------------------------- |
| `dev/test.R` (lean)                                           | 1 м 34 с | 1414 pass, 0 skip               |
| `dev/test.R '^plot-methods$'`                                 | 19 с     | 38 pass, 0 skip                 |
| `dev/test.R --full`                                           | 3 м 48 с | двухфазный; 37666 pass, 25 skip |
| было: `dev/test.R` (весь набор без внешних сверок, 2 воркера) | 4 м 03 с | 3133 pass, 15 skip              |

## `check.R` — приёмка перед коммитом

```sh
Rscript dev/check.R --quick     # рутинный цикл: roxygen, styler, lintr, docs/artifacts
Rscript dev/check.R             # гейт перед коммитом: + фигуры + install smoke
Rscript dev/check.R --no-render # гейт без фигур
Rscript dev/check.R --full      # релизный гейт: + R CMD check --as-cran
Rscript dev/check.R --spelling  # + орфография (англ. словарь — шумно на рус. докках)
Rscript dev/check.R --render    # + тяжёлые панели (мишени) — сеть/OligoArrayAux
```

`--quick` — для рутинного цикла: только синхронность `NAMESPACE`/`man/`,
`styler`, `lintr` и граф `docs/artifacts`. Он не запускает фигуры, install smoke
и `R CMD check`; орфография — только если явно передан `--spelling`,
комбинировать с `--full`/`--render` нельзя.
Обычный запуск (без флагов) остаётся гейтом перед коммитом: те же четыре шага
плюс фигуры и install smoke. `--full` — релизный гейт: добавляет
`R CMD check --as-cran`, внутри которого идут **все** тесты, включая
биологические и внешние сверки, — полный путь не ослаблен.

Шаги по порядку: `NAMESPACE`/`man/` синхронны с roxygen → `R/` и `tests/`
форматированы (`styler`) и без линтов (`lintr`) → `docs/artifacts` → орфография
(`spelling`, только с `--spelling`) → **фигуры** (см. ниже) → сборка и проверка
(`R CMD install`/`R CMD check`). Отсутствующий инструмент — это сообщение
«skip», а не падение; провал любого шага даёт ненулевой код возврата.

Замеры на этой машине (R 4.6.1):

| Команда                   | Время |
| ------------------------- | ----- |
| `dev/check.R --quick`     | 37 с  |
| `dev/check.R --no-render` | 39 с  |

Орфография вынесена за флаг: `inst/WORDLIST` (527 терминов) снимает шум от
химий, имён пакетов и локусов, но список пополняется вручную, поэтому шаг
включается явно (`--spelling`). Слова-филлеры и антипаттерны в комментариях
ловит отдельный `dev/prose-tics.R` (шаг гейта, см. ниже); `lintr` прозу не
проверяет.

## `audit-deps.R` — зависимости и поверхность функций

```sh
Rscript dev/audit-deps.R           # отчёт; exit 1 на явных ошибках
Rscript dev/audit-deps.R --strict  # + exit 1 на одинаковых телах функций
```

Статический аналог `deptry`/`vulture`: `Imports` без `pkg::`/`importFrom`,
неиспользуемые символы `importFrom`, имена, определённые дважды, внутренние
функции без вызовов и байт-идентичные тела. В гейт не входит — это отчёт;
результат и ограничения записаны в `docs/deps-audit.md`.

## `prose-tics.R` — филлеры и антипаттерны в прозе и комментариях

```sh
Rscript dev/prose-tics.R               # все десять уровней: счётчики и образец
Rscript dev/prose-tics.R --list        # + каждая находка целиком
Rscript dev/prose-tics.R --contrastive # только «X, not Y» (не гейтится)
Rscript dev/prose-tics.R --check       # ненулевой код на filler, comment, verbosity, prose_verbose, encoding
```

Читает `DESCRIPTION`, `README.md`, `man/`, `vignettes/` и roxygen-строки
`R/*.R`; слой `comment` смотрит все `#`-строки `R/*.R`. Десять уровней:

- `filler` («it's worth noting», «delve», «seamless», «moreover»…) — слова без
  информации; гейтит `--check`;
- `comment` — антипаттерны комментария: хеджирование («obviously», «basically»,
  «trivially»), разговор о себе или инструменте («as an AI», «the agent»),
  `TODO`/`FIXME`/`HACK` без владельца и комментарий, дословно повторяющий
  строку кода под ним; гейтит `--check`;
- `negation` — семейство «not X, it's Y» во всех формах: «is, not», «not but»,
  «not just», «rather than», «without», «unlike», «far from». Осознанный
  стиль репозитория (сотни совпадений), поэтому только счётчик; `--contrastive` —
  его алиас;
- `meta` — самоуказание: «the point is», «here's the thing», «importantly»,
  «note that», «at its heart», «serves as». Обычные связки («in practice»,
  «precisely because», «which is why») исключены; сейчас 0;
- `hedge` — настоящие смягчения: «simply», «basically», «seems to», «perhaps»,
  «of course», «in fact». Технические квалификаторы («actually», «very»,
  «really», «particularly», «especially», «highly») исключены; сейчас 4, все
  четыре — требования или измеренное поведение;
- `verbosity` — многословные обороты с коротким эквивалентом: «in order to»,
  «the fact that», «prior to», «a number of»; гейтит `--check`;
- `punctuation` — тире и «!!» только в бегущей прозе: строки разметки (таблицы,
  списки) сканер пропускает. Сейчас 0;
- `encoding` — не-Unicode сигналы: невалидный UTF-8, U+FFFD, мойбейк (`Ã`, `Â`,
  `â€`), zero-width (U+200B/C/D, U+FEFF) и управляющие символы в
  `DESCRIPTION`, `README.md`, `man/*.Rd`, `vignettes/*.Rmd`, `R/*.R`, `tests/`,
  `inst/{csv,txt,md,yml}`; гейтит `--check`;
- `comment_verbose` — блок обычных `#`-строк от 15 строк (баннер файла не в счёт)
  или строка шире 100 колонок (URL не считается);
- `prose_verbose` — абзац длиннее 120 слов без ссылки, `code` или вызова, абзац
  длиннее 150 слов либо блок вывода `##` длиннее 15 строк.

Последние восемь уровней печатаются счётчиком и восемью образцами (`--list` —
все). Гейтит `filler`, `comment`, `verbosity`, `prose_verbose` и `encoding`:
они держатся на нуле. `negation` (397) прочитан целиком: каждое попадание
называет технический контраст («data, not prose»), поэтому оставлена
осознанно. `comment_verbose` — шесть плотных блоков ограничений (прочитаны и
оставлены). Разбор каждого уровня и очередь работы — в
[`dev/lang_purity.md`](lang_purity.md).

Гейт `dev/check.R` (шаг «prose tics») запускает `--check`, так что `filler`,
`comment`, `verbosity`, `prose_verbose` и `encoding` не могут вырасти
незаметно.

## `render-all.R` — фигуры как код

```sh
Rscript dev/render-all.R              # всё: деревья, панель мишеней, смоук-плоты, screen
Rscript dev/render-all.R --skip-heavy # только деревья решений (быстро, без генома)
```

Графы решений раскладывает движок `.tools/elk` (ELK — слои и порты,
libavoid — маршрутизация; см. `.tools/elk/README.md`): стадии — колонки, рёбра
ортогональные. Рядом с каждым SVG лежит текстовый двойник `.txt`. Если движок не
запускается, шаг фигур падает с просьбой поставить его (`npm ci` в `.tools/elk`).

Картинки не рисуются руками: каждый `render-*.R` читает движок (схему решения,
константы гейтов, реестр схем), поэтому диаграммы следуют за пайплайном. Один
вход — `render-all.R`. Шаг «фигуры» в `check.R` вызывает его **на каждой приёмке**,
так что `man/figures/*.svg` (то, что в README) и `vignettes/figures/decision-*.svg`
(то, что в виньетках) не расходятся с кодом: если
перегенерированная картинка отличается, шаг **падает** с просьбой закоммитить
изменение — автообновление без тихого дрейфа. По умолчанию освежаются только
деревья решений (быстро, оффлайн); `--render` добавляет тяжёлые панели (панель
мишеней) — им нужны сеть/`OligoArrayAux`, на голой машине они скипаются
сообщением, а не падением. Растры `vignettes/figures/*.png` (git-ignored) просто
перерисовываются.

## `render-gallery.R` — рисунки для виньеток

```sh
Rscript dev/render-gallery.R
```

Прогоняет реальные дизайнеры на синтетической матрице и кладёт по одному
`plot(marker)` в `vignettes/figures/<scheme>.svg` (tracked) и `.png` (local,
в `.gitignore`); виньетки вставляют SVG через `include_graphics()`.

## `bench.R` — время и память по функциям

```sh
Rscript dev/bench.R
```

Прогоняет по представительному вызову горячих функций и печатает медианное время
и объём аллокаций. С `bench` в библиотеке берётся `mem_alloc`; на голой машине —
`system.time()` и базовый `Rprofmem()`. Нужен `OligoArrayAux` (см.
`data-raw/install-oligoarrayaux.R`) — без него термодинамические строки пропускаются.

## Инструменты (в `Suggests`)

`styler`, `lintr`, `spelling`, `bench`, `profmem`, `lobstr`, `pkgdown` (и их
зависимости) запинены в `renv.lock` — ставятся `renv::restore()`. `bench`/`profmem`/
`lobstr` не обязательны: `bench.R` откатывается на `system.time()` + `Rprofmem()`.
