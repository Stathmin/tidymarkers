## Закалка

- Полный набор: `Rscript dev/test.R --full` — **40916 pass, 0 fail**,
  2 warn (известный scan-batch), 28 skip (внешние движки и платформы).
- Релизный `Rscript dev/check.R --full` — `R CMD check` **clean**, 2 NOTE;
  примеры без OligoArrayAux — 210/210; стиль, линт, roxygen, доки и артефакты
  зелёные.
- Зависимости: 57 объявленных, 51 установлена, 6 недоступных Suggests;
  запрещённых лицензий нет (`dev/check-licenses.R`).
- Безопасность: внешние процессы запускаются только с константными бинарями
  и путями; единственный `eval(parse())` разбирает пакетные пороги, не ввод
  пользователя; секретов в `R/` и `inst/` нет.
- Гейт поверхности подключён к релизному прогону шагом `2e`; пангеномный
  пример называет сборки, поэтому checking примеров не падает.
- CI: шаг `dev/bench.R --gate` на linux release с ключом
  `github-ubuntu-latest`; без baseline для этого ключа он честно печатает
  `not_run`, а не зелёный.
- Порог критерия разбирается как AST и допускает только `c()` из чисел:
  `eval(parse())` больше не исполняет произвольный вызов.
