# Аудит зависимостей и функций

Статический аналог `deptry`/`vulture` для R: что объявлено в `DESCRIPTION`,
но не используется, что определено дважды и что никто не вызывает.
Скрипт — `dev/audit-deps.R`, запуск:

```sh
Rscript dev/audit-deps.R           # отчёт, exit 1 на явных ошибках
Rscript dev/audit-deps.R --strict  # + exit 1 на одинаковых телах функций
```

Это отчёт, а не шаг гейта: CI не должен краснеть из-за записи в `Suggests`,
которая нужна внешнему workflow. Явные ошибки (неиспользуемый `Imports`,
двойное имя, мёртвая внутренняя функция) скрипт всё же валит.

## Результат на 2026-11-27

Проверено: 32 `Imports`, 25 `Suggests`, 39 739 строк в `R/`,
961 функция верхнего уровня, 207 экспортов.

| проверка | найдено |
| --- | ---: |
| `Imports` без `pkg::` и без `importFrom` | 0 |
| символы `importFrom`, не упомянутые в `R/` | 0 |
| имена, определённые дважды | 0 |
| внутренние функции без вызовов | 0 |
| группы с байт-идентичными телами | 4 |

Одинаковые тела — это делегирование, а не копипаста:

- `capabilities.marker_engine` == `capabilities.genome_index` — один и тот же
  разбор `engine$capabilities` для двух классов движков;
- `marker_primers.marker_taqman` == `marker_primers.marker_dpcr` и
  `marker_map_taqman` == `marker_map_dpcr` — `dpcr` наследует пробный дизайн
  TaqMan, методы вызывают общий `probe_primers()`/`probe_map_spec()`;
- `vec_restore.marker_criteria` == `vec_cast.marker_criteria.*` — приведение
  к `marker_criteria` всегда идёт через `new_marker_criteria()`.

Одна запись удалена: `parallelly` стояла в `Suggests`, но не упоминается ни в
`R/`, ни в тестах, ни в CI; её тянут транзитивно (`testthat`), пакету она не
нужна.

## Что скрипт не видит

Это чтение текста, а не загруженного namespace:

- `getExportedValue()`, `requireNamespace()` и NSE (имя колонки, совпавшее с
  именем пакета) невидимы;
- S3-методы пропускаются: их зовёт диспетчеризация по классу, а не по имени;
- «идентичное тело» у методов — сигнал посмотреть, а не приговор: две
  делегирующие обёртки законно совпадают.

Поэтому попадание в отчёт значит «посмотреть сюда», а не «удалить это».
